# Quickstart Guide: Lightweight Swift Frontend

## Prerequisites
- macOS 13.0+
- Xcode 15+ / Swift 5.9+
- Python 3.10+ with `antra` backend dependencies installed.

## Setup & Execution
1. Open the Swift frontend package/project workspace.
2. Ensure Python backend is accessible in environment path.
3. Run the Swift application (`swift run` or via Xcode).

## Validation Scenarios
1. **Paste Link**: Paste a Spotify/YouTube link into the centered bar.
2. **Preview**: Verify album artwork and track title appear.
3. **Confirm & Download**: Click download button and verify file lands in `~/Music`.
